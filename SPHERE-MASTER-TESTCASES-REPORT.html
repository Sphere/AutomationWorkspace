Where the gaps are

The biggest areas still to automate: Accessibility (0 of 5), mobile hamburger navigation (0 of 5), Search results content, dedicated Notifications content, negative Login/Signup cases, and cross-browser (Firefox/Safari). The four big authenticated modules — Home, My Courses, Account, Course Detail — are fully automated.

Environment: every UI/E2E spec reads BASE_URL and defaults to production (sphere.aastrika.org); staging runs via npm run go → Staging. Note the landmine in .env: the variable named PROD_URL actually points at staging — verify before relying on it.
