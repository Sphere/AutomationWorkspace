How to read this

The manual report is the enumerated checklist a tester would walk by hand — one row per thing to verify, in one environment, for one user. The automation re-runs those same verifications unattended, then multiplies them across environments, roles, languages and schedules that no one has time to click through manually. The manual sheet is the floor; automation is what is actually running on top of it.

The multiplier the manual sheet can't show

The 70-row sheet is written for one org and one user. The same journey in automation runs for every org in src/config/orgs.ts — BNRC, SIHFWUP, MP, SHSB, DMHUP, PVTBIHAR, PVTUP, NHMUP, NHMMP, NHMMADHYA and more — across 26 org × role combinations, each with a freshly provisioned learner, on both production and staging. One manual pass would be 70 checks; the automation's equivalent is that journey repeated dozens of times a day, unattended.

Fixes the automation accumulated

Real defects and portal behaviours found once, then handled for good — the reason the automation diverged from a naïve translation of the manual steps.

What was foundPortalWhy a manual pass missed it
Course stuck below 100%e-KshamataEvery module consumed, yet completion never recorded — the post-assessment spans multiple question-sets and the answer key must be merged across them, or most questions go blank.
Course stuck at 86%SphereFinal assessment submitted after a single question; the portal never marked the course done.
Badge on prod, not on staginge-KshamataSame learner, same course — invisible from the course side where everything looked finished.
Certificates listed "1 of N"SphereLearner had earned several; the list showed one. A human eye reads "a certificate is there" and moves on.
Pages rendered only in HindiBothOn some orgs labels come back in Hindi only; English-only checks quietly passed over them (110 UAT tests had failed this way until matching went bilingual).
Silent login failureSphereBad credentials returned an anonymous session that looked logged in — failures surfaced 20 steps later for unrelated-looking reasons.
Signup rejected over 19 charsSphereAddresses longer than 19 characters were silently dropped at signup.
OTP reader grabbed the yearBothA generic digit-run match picked up "2026" instead of the real OTP; now matched by context.
Answer key source 403 for learnersSpherequestionset/v1 is forbidden to learners; only content/v3/hierarchy works, matched by option text not stem.
isVisible({timeout}) doesn't waitSphereRoot cause of flaky CI checks — the timeout is ignored, so the check raced the page.
